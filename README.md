# Shubhyam Nai — Portfolio

A responsive, static personal portfolio built with plain HTML, CSS and JavaScript. No build tools or server are required.

## Preview locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a **public** repository named `Shubhyam-f.github.io` (or another repository name if you prefer a project URL).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub will show the published URL in the Pages settings once deployment completes.

If the repository is named `Shubhyam-f.github.io`, the user site URL will be `https://shubhyam-f.github.io/`.

## Before publishing

- Verify all project descriptions and status labels.
- Add selected screenshots and links to project materials when ready.
- Add a professional contact email if you want one displayed publicly.
- Review the public repository contents; never upload private spreadsheets, credentials, personal data or confidential client files.

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, project filters, project detail dialogs and reveal effects
